# GoldenBoughsLib 金枝库

核心底层库，为所有其他模块提供公共 API 和框架。

## 包结构

```
mixin/                  Java Mixin 类
kotlin/
  api/                  能力/美德/网络包基类/行为树/物品接口
  client/               HUD/模型/粒子/渲染
  common/               属性/实体/物品/状态效果/网络包
  core/                 Lib.kt(@Mod) / LibClient / LibConstants
  events/               事件监听器
  event/                自定义事件
  init/                 注册初始化
  mixed/                Mixin 接口
  util/                 30+ 工具类
```

## LC 伤害系统

`LcDamageType` — PHYSICS（物理）/ SPIRIT（精神）/ EROSION（侵蚀）/ THE_SOUL（灵魂）
`LcLevel` — ZAYIN(1) / TETH(2) / HE(3) / WAW(4) / ALEPH(5)

易伤/防御属性：

- PHYSICS_VULNERABLE / SPIRIT_VULNERABLE / EROSION_VULNERABLE / THE_SOUL_VULNERABLE
- 默认值：PHYSICS=1.0, SPIRIT=1.0, EROSION=1.5, THE_SOUL=2.0
- PHYSICS_DEFENSE / SPIRIT_DEFENSE / EROSION_DEFENSE / THE_SOUL_DEFENSE

## 四德系统

`VirtueType`: FORTITUDE（勇气>最大生命）/ PRUDENCE（谨慎>最大理智）/ TEMPERANCE（自律>挖掘/击退）/ JUSTICE（正义>移动/攻速）/
COMPOSITE（综合）
`VirtueRating`: I(1) / II(30) / III(45) / IV(65) / V(85) / EX(101)
`AbstractVirtue` — Attachment 持久化 + Attribute Modifier

## 理智系统

- MAX_RATIONALITY MinAttribute，默认 20.0
- RATIONALITY_NATURAL_RECOVERY_WAIT_TIME / RATIONALITY_RECOVERY_AMOUNT

## 行为树

Composite: Sequence / Selector / Parallel / Weight
Decoration: Condition / Inverter / Repeater / Interrupt / TimeControl
Leaf: MoveToTarget / JumpAttack / Dash / AnimTrigger / Shoot / Wait / RandomStroll 等

工厂：BTFactory.sequence() / selector() / parallel() / wait() / repeat() 等
接口：IBehaviorTreeMob / IStateChangeableMob / IBlackboardHolder

## HUD/UI

状态栏 / 护盾层（4色伤害） / 滤镜层 / 粒子（DamageTextParticle）
GeoItemRenderer / GeoArmourRenderProvider / AutoGlowingRenderLayer
