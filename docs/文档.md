# GoldenBoughsLib（金枝库）

## 模块定位

ImaginaryCraft 项目的**核心底层库**，为所有其他模块提供公共 API、工具类和框架。Kotlin 优先，仅 mixin/accessor 保留 Java。

## 命名规范

- **接口**: `I` 前缀（如 `IEntityLib`, `IVirtue`, `IBehaviorTreeMob`）
- **Mixin 接口**: `mixed/` 包下，`I` 前缀，通过 KMixin 自动生成
- **包名**: 全小写 snake_case（`architecture`, `goldenboughs_lib`）
- **常量**: `UPPER_SNAKE_CASE`，通常在 `companion object` 中

## 关键系统

### 美德系统（Virtue）

`api/virtue/` 包，四种美德（刚毅 Fortitude、正义 Justice、谨慎 Prudence、节制 Temperance），支持等级评估和属性修饰。

### 能力系统（Capability）

`api/capability/` 包，为 Block/Entity/Item 提供 `LcLevel`（等级）、`LcDamageType`（伤害类型）、`UsageReq`（使用需求）能力。

### 行为树框架（Behavior Tree）

`api/world/entity/ai/behavior/` 包：

- **根节点**: BTRoot / BTCommonRoot / BTBossTwoStageRoot
- **组合节点**: Sequence / Selector / Parallel / Weight
- **装饰节点**: Condition / Inverter / Repeater / RepeatUntil / TimeControl / Interrupt
- **条件节点**: Time / Distance / Health / TargetExist / Navigation / Angle 等 13 种
- **叶子动作**: Move / Jump / Dash / Shoot / Wait / AnimCtrl / SyncFlag 等 22 种
- **黑板系统**: IBlackboardHolder / Blackboard / KeyType

### HUD 图层系统

`client/gui/hudlayers/` 包，可组合的多层 HUD，支持状态栏、护盾栏（物理/灵魂/精神/侵蚀）、理智条、斩味特效、伤害/理智屏幕滤镜。

### 粒子系统

`client/particle/` 包，支持伤害图标粒子和文本粒子（含描边/对齐/构建器）。

## 事件规则

- `@EventBusSubscriber` 自动选择 bus，只需 `modid` 和 `value`
- 事件按事件类分类，放在 `events/`（公共）或 `events/client/`（客户端专属）
- 事件 subscriber 只做转发，业务逻辑放工具类
- 跨类调用必须带类名（`ClassName.method()`）
